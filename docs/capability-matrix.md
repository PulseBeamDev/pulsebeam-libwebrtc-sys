# Linux x86_64 capability and evidence matrix

This is a focused matrix of existing Linux x86_64 binding paths, not a complete public SDK declaration inventory. The [pinned SDK inventory and mapping](native-sdk-coverage.md) defines the scope independently of the implemented subset. The public API and evidence links below describe only their stated behaviors. **Pass** means the named test actually exercises the claim with a matching artifact. **Partial** means only the specified subset is exercised. **Gap** means no qualifying API or test exists. Headless tests do not qualify a physical device or all possible libwebrtc background work. Real SFU interoperability belongs to the higher-level project.

**QA boundary:** Qualify our Rust/CXX adapter with focused public-API smoke and integration tests: construction, negotiation/configuration, encoded bypass, representative payload/metadata identity, explicit rejection, backpressure, and shutdown. Trust the pinned upstream libwebrtc QA for codec correctness, the exhaustive simulcast/SVC and RTP metadata combination space, physical device behavior, and desktop portal implementations. Do not require an exhaustive adapter-side codec/profile/layer test matrix or live hardware/display qualification. A smoke test only establishes the exercised adapter path; it does not turn an unimplemented API or a demonstrated failure into a pass. Record fixture-dependent or unexercised adapter behaviors as such, rather than describing them as upstream failures or silently counting them as passed.
